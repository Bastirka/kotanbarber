# Kotaaans Barbershop

Static landing page for Kotaaans Barbershop in Rezekne.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:5173/`.

## Deploying to Vercel

This project is a plain static site with `index.html` at the repository root.

Recommended Vercel settings:

- Framework Preset: `Other`
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: `npm install`

Vercel can also detect the project automatically after GitHub import.
